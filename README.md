# Pixel Plus Merch Store

Внутренний сайт для обмена Пиксель бонусов на корпоративный мерч.

## Возможности

- каталог товаров из Google Таблицы;
- отображение наличия и остатков;
- выбор размера для товаров с размерной сеткой;
- корзина с сохранением между перезагрузками;
- ограничение до трёх единиц каждого товара;
- самовывоз из офисов и доставка до Ozon;
- проверка минимальной суммы и доступного баланса;
- отправка заказа в Google Apps Script с email-уведомлением;
- подготовка письма с идеей нового мерча.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```powershell
python -m http.server 4176
```

Сайт будет доступен по адресу `http://127.0.0.1:4176/`.

## Данные

Каталог загружается из Google Apps Script. Для новых товаров используются поля:

- `id`, `title`, `desc`, `price`;
- `image`, `size`, `color`;
- `В наличии`;
- при необходимости `stock`/`Остаток` и `sizes`.

## Ограничения

Баланс бонусов сейчас вводится сотрудником и проверяется вручную. Для
производственного запуска нужна серверная проверка баланса через TEAM и
атомарное резервирование остатков.
